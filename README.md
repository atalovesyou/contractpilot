# ContractPilot — AI Contract Generator for Freelancers

**Generate contracts, review client contracts for traps, and get negotiation scripts.** 40+ clause patterns, 6 project types, PDF export.

🔗 **Live:** [https://atalovesyou.github.io/contractpilot/](https://atalovesyou.github.io/contractpilot/)

## Features

- **Contract Generator** — 6 project types (web dev, design, marketing, video, writing, consulting)
- **Smart Clause Toggles** — IP ownership, payment terms, revisions, NDA, kill fee, non-compete
- **Contract Review** — Risk analysis with clause-by-clause breakdown
- **Negotiation Scripts** — 3 tones for pushing back on unfair terms
- **Template Gallery** — Pre-built contract templates for common freelancer scenarios
- **PDF & TXT Export** — Professional formatting with headers and page numbers
- **100% Client-Side** — Your contracts never leave your browser
